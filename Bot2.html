How V4 Works

1. REAL DATA: The engine accepts only ticks received from Deriv. It does not create fake ticks, random prices, simulated outcomes or invented historical data.

2. DATA VALIDATION: Every accepted tick must contain a valid quote and timestamp. Invalid or malformed messages are rejected.

3. FEATURE ENGINE: The system examines recent digits, one-digit transitions, two-digit transitions, three-digit contexts, digit frequencies, streaks and entropy.

4. ENSEMBLE: The different models are combined instead of relying on one transition table.

5. CALIBRATION: Raw model confidence is adjusted using previously resolved predictions. Calibration uses actual outcomes only.

6. SIGNAL GATING: The system does NOT have to predict every tick. If evidence is too weak, the engine displays NO VALID SIGNAL.

7. VERIFICATION: A prediction becomes WIN or LOSS only after the next real Deriv tick arrives and supplies the actual next digit.

8. LEARNING: Model weights change slowly from verified results. The system cannot improve itself using assumptions or fabricated results.

9. WALK-FORWARD VALIDATION: Historical testing proceeds chronologically. The model only learns from information available before each test prediction.

10. NO GUARANTEE: Historical accuracy does not guarantee future market results. A high displayed probability is not a promise of a winning trade.
